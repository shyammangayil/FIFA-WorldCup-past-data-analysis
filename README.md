# FIFA World Cup Analytics

A data analysis and machine learning project exploring the history of the FIFA World Cup using tournament-level and team-level statistics.

## Overview

This project analyzes historical FIFA World Cup data to identify patterns, trends, and factors associated with tournament success.

The repository currently focuses on:

* Exploratory Data Analysis (EDA)
* Historical tournament analysis
* Team performance metrics
* Goal-scoring trends
* Champion and runner-up comparisons
* Feature engineering for predictive modeling

Future work includes survival analysis, ranking systems, and World Cup outcome prediction.

---

## Dataset

The analysis uses historical FIFA World Cup data including:

### Tournament-Level Data

* Year
* Host nation
* Champion
* Runner-up
* Third-place team
* Number of participating teams
* Number of matches
* Goals scored
* Average goals per game

### Team-Level Data

* Team
* Games played
* Wins
* Draws
* Losses
* Goals scored
* Goals conceded
* Goal difference
* Points

## Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-username>/fifa-world-cup-analytics.git
```

Install dependencies:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

Launch Jupyter:

```bash
jupyter notebook
```

Open:

```text
FIFA.ipynb
```
